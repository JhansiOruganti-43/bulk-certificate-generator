# AEREO Bulk Certificate Generator API

This is the AEREO Software Development Intern assignment.

## Phase 1
- FastAPI Backend Setup with Health Check
- SQLite + SQLAlchemy Database Configuration
- React + Vite Frontend scaffolding

## Setup Instructions

### Backend
1. Navigate to the `backend` directory.
2. Create a virtual environment: `python -m venv venv`
3. Activate it:
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run the server: `uvicorn app.main:app --reload`
6. View API docs at: `http://localhost:8000/docs`

### Frontend
1. Navigate to the `frontend` directory.
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. View the app at: `http://localhost:5173`
